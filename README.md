- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- Git & GitHub

## Getting Started

Clone the repository:

```bash
git clone <your-repository-url>
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```
